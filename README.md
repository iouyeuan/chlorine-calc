# 儲水桶／水車餘氯補添加計算

離線可用的單頁計算工具，用於依檢測餘氯與剩餘水位（分滿）判斷是否需補添加次氯酸鈉，並計算添加濃度與預估總餘氯。

## 使用

- 網頁：<https://iouyeuan.github.io/chlorine-calc/>
- 手機可從瀏覽器「加入主畫面」，以獨立視窗開啟。
- 亦可下載 `index.html` 在本機離線開啟（本機 `file://` 不會註冊 service worker）。

## 計算說明

- 餘氯低於 0.5 mg/L 時需補添加。
- 原液以有效氯 10%（100000 mg/L）計。
- 儲水桶以 1 m³ 為滿槽；10 分滿 = 1000 L。
- 添加濃度（mg/L）= 體積（mL）× 100 ÷（分滿 ÷ 10 × 1000）。
- 表列水位（3、5、7、10 分滿）依建議添加量表顯示建議量；非表列水位以公式計算，並標示「非表列」。

本工具不調整表上數值，僅協助對照與驗算。
